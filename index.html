市场 / 类型URLHTTP结论问题摘要
数据来源：测试站原始 HTTP 源码 + 无头浏览器完整渲染 DOM（含滚动），共 574 页（287 基础 + 287 个 ?12345 加参探测页）。
七个维度：基础 Head / TDK / Canonical·Robots / Hreflang / 社会化分享 / 结构化数据 / SSR 模块直出。
Canonical 规则：搜索页保留 q 并剥离其余参数；其余页面一律剥离全部查询参数。加参页 robots 必须 noindex,follow。
SSR 判定基于源码与渲染 DOM 的模块级对比；数据本身缺失标为「内容为空」，不按技术故障处理。
