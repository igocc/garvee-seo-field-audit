# GARVEE 三站 SEO / GEO 整改清单

对 GARVEE 美国站、英国站、加拿大站测试环境的审计，**SEO 与 GEO 分两条赛道**。
按「模块 × 站点 × 页面类型 × 具体问题点」四层组织。

## 怎么看

```
模块（47 个）
  └─ 站点（美国站 / 英国站 / 加拿大站）
       └─ 页面类型（首页 / 类目 / 商品 / 搜索 / 博客 / 活动 / 底部页）
            └─ 具体问题点（BreadcrumbList[*].item.@id、llms.txt…）
```

点击任一模块行即可展开该三层结构。

## 结构化数据依据

以 Schema.org 官方定义为准。**所有 URL 属性必须绝对路径**：

| 字段 | 当前（错） | 应改为 |
|---|---|---|
| `BreadcrumbList[1].item.@id` | `/` | `https://<域名>/` |
| `BreadcrumbList[2].item.@id` | `/blogs/buying-guides` | `https://<域名>/blogs/buying-guides` |

## 已知边界

- 测试环境结果，不等同生产现状
- 44 页返回 4xx，为站点自身路由问题；错误页只判标题与 robots
- `llms.txt` 为站点级文件，需单独 GET 验证
- hreflang 按标记判定，未做实际抓取互返验证
- 未覆盖：JSON-LD 值与页面实际内容逐项比对、Core Web Vitals
